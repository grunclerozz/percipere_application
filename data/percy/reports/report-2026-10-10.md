# Percy intent classifier — training report (2026-10-10)

Dataset: `data\percy\intents.csv` — 496 rows,
495 distinct sentences after preprocessing (1 repeat(s) dropped), 26 intents.
Split (stratified, seed 42): train 346, validation 74, test 75.
Features: TF-IDF word 1–2-grams + character 3–5-grams
inside words (3353 features on train + validation).
Exported models are trained on train + validation; the test set was never seen.

## Chosen model
**Logistic Regression (C=3.0, class_weight=None)** → `assets/percy/model.json` (version `2026-10-10-495`).
Why: Logistic Regression (C=3.0, class_weight=None) had the higher validation macro F1 (0.568 vs 0.564). The other model is exported as `assets/percy/model_alt.json`.
