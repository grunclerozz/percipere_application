# Percy intent classifier — training report (2026-10-11)

Dataset: `data\percy\intents.csv` — 514 rows,
513 distinct sentences after preprocessing (1 repeat(s) dropped), 27 intents.
Split (stratified, seed 42): train 359, validation 77, test 77.
Settings are tuned by stratified 5-fold cross-validation on train + validation
(436 sentences); the test set is used only for this report.
Features: TF-IDF word 1–2-grams + character 3–5-grams
inside words (3482 features on train + validation).
Exported models are trained on train + validation; the test set was never seen.

## Chosen model
**Logistic Regression (C=100.0, class_weight=balanced)** → `assets/percy/model.json` (version `2026-10-11-513`).
Why: Logistic Regression (C=100.0, class_weight=balanced) had the higher 5-fold cross-validation macro F1 (0.621 vs 0.600). The other model is exported as `assets/percy/model_alt.json`.
