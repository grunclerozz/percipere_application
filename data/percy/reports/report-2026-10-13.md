# Percy intent classifier — training report (2026-10-13)

Dataset: `data\percy\intents.csv` — 529 rows,
527 distinct sentences after preprocessing (2 repeat(s) dropped), 27 intents.
Split (stratified, seed 42): train 368, validation 79, test 80.
Settings are tuned by stratified 5-fold cross-validation on train + validation
(447 sentences); the test set is used only for this report.
Features: TF-IDF word 1–2-grams + character 3–5-grams
inside words (3561 features on train + validation).
Exported models are trained on train + validation; the test set was never seen.

## Chosen model
**Logistic Regression (C=30.0, class_weight=balanced)** → `assets/percy/model.json` (version `2026-10-13-527`).
Why: Logistic Regression (C=30.0, class_weight=balanced) had the higher 5-fold cross-validation macro F1 (0.663 vs 0.621). The other model is exported as `assets/percy/model_alt.json`.
