# 07 — Key decisions and why

**Record every new or changed decision here** (add a row, newest at the bottom of the table,
keep the date). For a long write-up with alternatives and measurements, also add a dated entry
to `docs/specs/decisions.md` (newest first) and point to it in the "Where" column.
If a decision is reversed, don't delete the old row: add a new row that says what replaced it.

| 2026-10-16 | Percy smarter uses a fixed, team-written-only held-out test set; generated Codex rows are training-only | Thesis evaluation must not score phrases generated for model training | `data/percy/test_team.csv`, `docs/handoff/percy-smarter-handoff.md` |
| 2026-10-17 | **A late valid voice result is never thrown away**: giving up waits 1.5 s and a late result cancels the message and runs (replaces the 2026-10-16 "discard the session on giving up") | The message came and then the command ran; users lost trust in the voice | `03-voice-and-percy.md` → Voice reliability |
| 2026-10-17 | Only sessions **without any mic sound** count toward "voice not working"; stale events of a session the app just closed restart quietly | Busy/stale Android events made a working recognizer look dead | `lib/core/voice/voice_controller.dart` |
| 2026-10-17 | The "listening" tone plays when the mic really delivers sound, not when listening is requested | Words said between the tone and the mic opening were lost | `lib/core/voice/voice_controller.dart` |
| 2026-10-17 | Noise: only low-risk measures (phone noise suppressor on the app's mic, AGC off; ask back unsure commands in noise from 0.45 similarity). No noise model, no engine switch; Percy thresholds unchanged | Defense is close; heavy models are future work | `lib/config/voice_config.dart` |
| 2026-10-16 | Percy evaluation: primary score = fixed team-only test set (`test_team.csv`, never trained on, never reshuffled); all-data 70/15/15 split and 5-fold CV are secondary; model chosen by 5-fold CV on training data only; training rows matching a test phrase after preprocessing are dropped; `train.py` will not train until each new intent has 8+ team test phrases | A score on phrases the model trained on, or on generated text, would not be honest thesis evidence | `scripts/percy/train.py`, `scripts/percy/validate_dataset.py` |
| 2026-10-16 | Hold-to-listen stays the existing long-press (`longPress` → `listen`), with the hold time in `VoiceConfig.holdToListen`; TalkBack gets the same action as a custom semantics action; Android recognizer errors are ignored while the offline recognizer is listening | One gesture to stop speech and talk; false "voice not working" stops | `lib/core/gestures/`, `lib/core/offline_voice/hybrid_speech_input.dart` |
| 2026-10-17 | Phase 6D algorithms built: Laplacian-variance + brightness check after each camera capture (spoken tip + retake offer), Otsu OCR fallback when the first read is weak (< 20 chars or confidence < 0.60; keep the result with more valid words), word-level WER calculator with a hidden developer test screen; thresholds in `lib/config/image_quality_config.dart` | Thesis needs four own algorithms; tips help users who cannot see the photo; Otsu only as fallback so good photos are untouched and never used on the Maglarawan picture | `docs/thesis/algorithms.md` |
| 2026-10-17 | **Loading screen on every cold start** (after the first-launch download when needed): voice, recognizers (with Whisper's warm-up), Percy and ML Kit load before the first screen; nothing listens or prompts meanwhile; 15 s limit, then the rest loads in the background | Tablet test: voice errors and "say it 2–3 times" at app start while engines loaded behind the first screen | `lib/features/startup/startup_screen.dart`, `03-voice-and-percy.md` |
| 2026-10-17 | While loading or processing (startup, models, OCR) and 4 s after, failed listening sessions restart quietly and never count toward "Hindi gumagana…"; a failed recognizer set-up is retried (3 tries with nothing loading before "no recognizer") | A busy recognizer is not a broken one; one failed set-up at startup disabled voice for the whole run | `lib/core/voice/voice_readiness.dart`, `voice_controller.dart` |
| 2026-10-17 | **Push-to-talk** on the gesture area: hold (now 450 ms, was 650 ms) = stop speech + listen while held, release = finish after 0.4 s grace; tap/voice ways unchanged; TalkBack: held touch or long-press action (replaces the 2026-10-16 hold-to-listen row's timing) | User request after the tablet test; the user decides when they are done talking | `lib/core/gestures/`, `lib/config/voice_config.dart` |
