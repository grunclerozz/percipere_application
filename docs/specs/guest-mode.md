# Guest mode: "Subukan muna (Try first)" (Phase 6B)

- **One local guest profile per device** (`users.is_guest = 1`), never synced, reused if
  the user picks "Subukan muna" again.
- **Short profiling:** Steps 1 (navigation mode), 4 (voice language), 5 (speed) and the
  summary. Defaults for the rest; full setup available in Settings.
- Guests can use all reading features and settings, and send feedback marked anonymous
  (feedback itself is Phase 7). **No fingerprint login** for guests.
- **Guest → account:** when a guest registers, move their preferences and reading history
  to the new account, delete the guest profile, and ask only the profiling steps they
  haven't done yet.
- **Registration reminders:** at most once each, at natural moments — the first save to
  history, and in Settings: "Naka-save ito sa phone na ito lamang. Mag-register para hindi
  ito mawala." **Never during reading or setup.**
